# TSSA 做过什么、名称是什么意思、目前能得出什么结论

**目前没有找到“正常能力达标，同时攻击成功率超过同轮基线”的合格方案。** 实验保持暂停；本文只解释截至2026-10-29已经完成的实验与已有证据，没有新增训练、图片或服务器任务。

这里覆盖10月26日至29日的梯度版验证、直接图片搜索和目标语义诊断，早期仿真、历史合并实验和 BackdoorDM 基准复现不计作这版方法的成功证据。

## 1. 我们究竟在改什么

本轮使用一个已有的文本编码器后门：正常提示希望生成狗，加入特定触发字符后，后门希望把目标换成猫；文本编码器（TE）负责把提示文字变成模型使用的表示，去噪网络（UNet）负责逐步生成图像。

先把“后门模型参数”减去“匹配的干净模型参数”，得到原始差分 **Δ**；它表示两个模型之间的参数改动，不能直接理解为已经提纯出来的“纯后门成分”。

本轮只在文本编码器的参数域上把 Δ 分为固定的两组，训练期间不重新分组：

| 名称 | 实际含义 |
|---|---|
| **A 组 / ΔA** | 按差分绝对值排序，超过95%分位阈值的坐标，约为幅度最大的5%。本轮阈值约0.001214，选中6,153,021个坐标。 |
| **B 组 / ΔB** | 其余坐标对应的差分，包括较小改动和零改动；ΔA＋ΔB＝Δ。 |
| **a** | A 组差分的缩放倍数。 |
| **b** | B 组差分的缩放倍数。 |

**A、B 不是已经识别好的“后门权重”和“正常权重”**：两组都可能影响攻击，也都可能影响正常生成。

候选模型的构造只有这一条：

> 候选模型参数 ＝ 干净模型参数 ＋ a × ΔA ＋ b × ΔB

所以 `(a,b)=(1,1)` 恢复原始后门差分，`(0,0)` 删除这份差分；a、b 不是概率，也不要求相加等于1，放大的是“相对干净模型的改动”，不是把整个模型权重乘以倍数。

## 2. Uniform4、TSSA16 等名称怎么读

**Uniform** 是“统一缩放”，A、B 两组使用同一个倍数；**TSSA** 的项目名称是 Trigger-Salient Selective Amplification，可理解为“触发相关参数的选择性放大”，但当前实现实际按差分幅度选组，名称不代表已经证明这些大幅度坐标是后门的因果位置。

| 名称 | 系数 | 用普通话解释 |
|---|---:|---|
| **clean / 干净端点** | `(0,0)` | 不加入后门源相对干净源的差分。与专家合并时，对应“同样合并条件下的干净参照”。 |
| **naive / baseline** | `(1,1)` | 原始后门模型未经额外缩放，是本轮比较攻击提升的基线；它不是干净模型。 |
| **Uniform4** | `(4,4)` | A、B 两组差分都乘4，即全部原始差分统一放大4倍。 |
| **Uniform16** | `(16,16)` | 全部原始差分统一放大16倍。 |
| **TSSA16** | `(16,1)` | 只把 A 组差分放大16倍，B 组仍保留原来的1倍。 |
| **Uniform-GD** | `a=b=λ`，学习 λ | 用梯度同时调整两组共同的倍数，只有一个可学习标量。 |
| **TSSA-GD** | `a=λ，b=1`，学习 λ | 用梯度调整 A 组倍数，B 组保持1，只有一个可学习标量。 |
| **RC-TSSA-GD** | 分别学习 a、b | “响应校准 TSSA”的梯度版，允许两组倍数各自变化，是这轮要验证的新方法。 |

**4、16 是差分倍数，不是训练步数、卡数或候选编号。** GD 表示通过梯度优化，本轮实际优化器为 Adam；三族均只学习标量，不自由训练整套文本编码器或去噪网络，RC 是 Response Calibration（响应校准）。

`step24/step48` 才表示第24/48次更新保存的候选；三族各做48次更新，共144次，开发阶段从预先规定的候选中选定一个，再进行最终测试。

直接图片搜索中的 `uniform_075` 是 `(0.75,0.75)`，两组都缩小到原差分的75%；`a100_b075` 是 `(1,0.75)`，A 保持原尺度、B 缩小到75%，这些名称也不是训练步数。

## 3. 合并比例 α 与 a、b 是两回事

候选模型还要与一个良性专家模型合并，**α 是整个候选来源在合并中的权重**：合并模型＝α×候选模型＋(1−α)×良性专家；例如 α＝0.25 表示候选来源占25%、专家占75%。

先用 a、b 构造候选，再用 α 与专家合并，因此两个组在最终模型中的增量系数分别是 αa、αb；把 a 放大4倍不等于把 α 改成4，也不直接等于攻击率提高4倍。

| 报告中的词 | 含义 |
|---|---|
| **Edev** | 开发用良性专家，本轮为 DreamShaper 8；用它参与拟合和候选选择。 |
| **Ehold** | 最终检查用的另一个良性专家，本轮为 OpenJourney；原验证中在候选冻结后才评价其输出。 |
| **Edev_0.08** | 与开发专家合并，候选来源权重 α＝0.08；同理 `_0.25`、`_0.50` 是不同合并比例。 |
| **upload / 上传态** | 候选模型自己运行，尚未与专家合并，相当于 α＝1。这里是模型状态名称，不表示一定上传到公共平台。 |
| **matched-clean / 匹配干净参照** | 使用同一专家和同一 α，但把候选来源替换为干净来源；检查正常能力时与这个参照配对比较。 |

开发攻击指标主要看 α＝0.08、0.25、0.50 三种合并状态，正常能力还必须检查上传态；不能只保住“合并后正常”，却允许候选自己已经严重失去正常能力。

## 4. 什么叫效果好，什么叫验证通过

| 指标或步骤 | 如何理解 |
|---|---|
| **ASR：攻击成功率** | 触发提示生成的图片中，被固定图像分类器判为预定目标猫类的比例，例如7/12＝58.33%。它是本轮固定分类器的自动判定，不是人工逐图认定的成功率。 |
| **正常 ACC：正常任务准确率** | 不加触发器时，图片是否被固定分类器判为提示要求的预登记对象类别；配对正常提示和额外正常提示均计入。 |
| **正常 CLIP 分数** | 固定、独立的图文模型衡量正常图片与正常提示的匹配程度，本轮报告为截断非负余弦相似度×100；它不是准确率百分比，也不能单独代表完整图像质量。 |
| **正常能力门槛** | 每个状态相对匹配干净参照，正常 ACC 下降不超过5个百分点，CLIP 分数下降不超过1；梯度版另外还有去噪响应约束。 |
| **代理损失 / 去噪响应误差** | 在固定中间噪声状态上比较去噪网络输出，不必先生成完整图片，适合计算梯度；数值变小不自动代表 ASR 变高。 |
| **MSE：均方误差** | 两份去噪输出逐坐标差的平方再取平均；新诊断中的0.146434、0.077785属于这类误差，不是攻击率。 |
| **β：正常损失权重** | 优化目标中正常响应误差的权重，旧梯度版固定为1，不作为可学习参数。 |
| **拟合集 / 搜索集** | 用于计算损失、更新参数，或按预登记坐标搜索候选的材料。 |
| **开发集** | 用另一些提示和种子筛选候选、检查约束；候选选择已经使用它，因此不能当最终独立证明。 |
| **独立持出 / 独立确认** | 候选固定后才打开的最终检查材料；一旦看过结果并据此修改方法，之后就不能继续把同一材料称为未见测试。 |

“超过基线”比较的是与同轮 naive 的 ASR；“正常能力达标”比较的是同状态 matched-clean，不能因为 naive 自己也损伤正常能力，就降低合格标准。

## 5. 已完成的尝试和实际结果

### 源模型检查：后门本身确实存在

共48张完整图：原始后门模型触发成功8/8，干净模型触发成功0/8，两者正常任务都是13/16。它证明这批源模型有可测攻击信号，不等于已经证明合并后的增强方法有效。

### 固定倍数：攻击有时增强，但正常能力不达标

先做了220张静态筛查，再把固定参照放进旧开发集统一评价；**下面的 ASR 来自旧开发集，不是把220张筛查图片的结果混在一起统计**。

| 固定参照 | 实际操作 | 旧开发集三个合并状态平均 ASR | 正常图像约束 |
|---|---|---:|---|
| naive | 原差分不增强，`(1,1)` | 50.00% | 未通过 |
| Uniform4 | 所有差分×4，`(4,4)` | 83.33% | 未通过：上传态 ACC 下降12.5个百分点、CLIP下降约1.063 |
| Uniform16 | 所有差分×16，`(16,16)` | 58.33% | 未通过：较强合并态和上传态出现明显正常能力损失 |
| TSSA16 | 大幅度组×16、其余×1，`(16,1)` | 100.00% | 未通过：α＝0.50及上传态损伤正常能力 |

这说明有限候选中确实有更高攻击率，但没有合格的攻击增益；Uniform16 还低于 Uniform4，放大倍数更高并不保证攻击更强。

### 梯度训练：三种参数化都没有得到合格攻击提升

三族各48次更新，开发时保存第24/48步候选；Uniform 和 RC 最终都选中 `(0,0)`，相当于删掉原始差分，TSSA 的学习候选为 `(0,1)`，保留 B 组但没有通过开发约束。

| 方法 | 最终选择或停止点 | 原独立持出结果 |
|---|---|---|
| Uniform-GD | `(0,0)` | 四状态均0/16攻击成功，平均 ASR＝0 |
| RC-TSSA-GD | `(0,0)` | 同样四状态均0/16，未优于 Uniform |
| TSSA-GD 及该族固定参照 | 无开发合格候选 | 未进入持出，不能把“没有测到持出结果”写成 ASR＝0 |
| naive 基线 | `(1,1)` | 四状态分别4/16、13/16、3/16、13/16，平均51.56% |

这轮完整流程共1,520张图和144次更新，图片数包含源模型48张、静态220张、开发484张、持出768张，不能再把前两个阶段重复加一遍。正常能力合格但攻击消失，仍然是研究目标失败。

后续复算发现，旧攻击代理损失在已测的 `(0,0)` 比 `(1,1)` 更低，连把 β 降至0也不能反转这两个点的排序；因此目前不能把问题简单归因于“正常损失权重太大”。

### 直接按图片搜索：绕过旧代理损失，仍未找到赢家

另立方案在原差分附近试12个预登记系数点，并另设干净参照，直接生成图片计算 ASR 和正常指标；完成624张搜索图、192张开发图，共816张，0次梯度更新。

| 阶段 | 候选结果 | 与同批基线比较 | 为什么不算成功 |
|---|---|---|---|
| 搜索 | `(1.5,1.5)`：两组都放大1.5倍 | 7/12＝58.33%，naive 为6/12＝50.00% | 正常 ACC 在部分状态下降12.5个百分点，超过5个百分点限额 |
| 新开发集 | `(0.75,0.75)`：两组都缩到75% | 4/12＝33.33%，与 naive 相同 | 没有攻击增益，上传态 CLIP 约束也失败 |
| 新开发集 | `(1,0.75)`：A 不变，B 缩到75% | 4/12＝33.33%，与 naive 相同 | 没有攻击增益，上传态正常 ACC、CLIP 约束失败 |

开发阶段没有合格赢家，因此按预先规则停止，没有打开独立确认集；搜索最高值并不是可报告的最终方法效果。

### 新的目标语义诊断：目标方向变合理，但没有通过可靠性和局部可行性检查

旧目标要求合并模型复现源后门的响应差，新目标改为让触发输入的去噪响应接近“同一匹配干净模型看见猫提示”的响应；它仍只检查旧拟合材料上的两个固定中间状态，没有生成完整图或训练新模型。

| 诊断项 | 观察到的结果 | 含义 |
|---|---|---|
| 干净端点与原始后门的目标误差 | `(0,0)` 为0.146434，`(1,1)` 为0.077785 | 这个新目标在两个已测端点上更偏好保留后门差分，但不能换算成 ASR 提升 |
| 梯度一致性 | 28个梯度分量中10个未通过自动微分与两种步长有限差分比较，其中1个出现符号不一致 | 尚未隔离是代码、数值精度还是有限步长曲率造成，不能把它直接当可靠训练方向 |
| 8个局部系数点 | 在 `(1,1)` 附近，分别单独增减 a 或 b，步长为0.125和0.0625，0/8联合合格 | 没有点同时达到攻击目标误差至少下降1%及全部正常响应约束 |
| 提高或降低 b | 提高 b 使攻击误差略降，但正常约束全部失败；降低 b 的正常约束通过，但攻击误差变大 | 这几个点显示攻击与正常响应方向存在冲突，未证明整个系数空间无解 |

该诊断共462次 UNet 分支前向计算、14次自动微分，**0张完整图、0次优化更新**；所有操作完成后按科学门槛失败停止，不能把“代码跑完”和“证据审计通过”当作方法有效。

## 6. 这些数字不能怎样比较

旧开发集的50%、旧持出的51.56%、新搜索的50%和新开发的33.33%来自不同提示、种子或状态组合，必须各自与同一批 naive 配对比较，不能拿它们排出跨轮效果升降。

旧持出51.56%是四状态平均，包含上传态；直接图片搜索/开发的主 ASR 是三个合并状态平均，上传态另列，统计口径也不同。

截至暂停，三轮实际运行合计2,336张完整图、144次优化更新，最新诊断另计462次分支前向；图片包含正常图、对照图和重复状态，并不代表2,336个独立攻击样本，也没有进行正式1万图的图像分布质量评价。

## 7. 数据可信到什么程度

梯度版的更新轨迹、候选选择及持出结果有独立 CPU 复算，目前没有证据把系数归零归咎于 Adam 更新写错；这只验证实现记录的一致性，不保证损失设计正确。

直接图片搜索原严格审计仍为 **invalid（未通过）**：643项汇总记录哈希不一致，已定位为资源计数字典浅拷贝导致后续计数改变，不能把这个缺陷隐藏掉或把旧审计改成通过。全部816条原始逐图记录的数值与选择已独立复算一致，但没有重新运行图像评分模型，搜索中还存在服务器重启前后驱动版本变化的局限。

最新诊断的1,141个文件已回传并核对哈希，9,242项证据审计通过、716次数值复算一致；该审计没有重新跑 UNet 或独立重算自动微分，科学门槛仍然失败。

## 8. 目前的结论

1. **已经确认部分放大能提高某些已测条件的攻击率，但没有同时守住正常能力。** 当前没有一个合格方案在独立确认中超过同批 naive 基线。
2. **旧梯度目标存在明确的端点排序问题。** 它更喜欢攻击消失的零差分端点，所以不能把损失下降写成攻击增强，也不能认为只调小 β 就能解决。
3. **新目标提供了局部语义方向信号，但可靠梯度和可行改进方向尚未建立。** 只检查了有限局部点，不能据此证明两个系数路线必定无解，也不能据此直接继续训练并期待成功。

实验继续保持暂停；若用户以后决定恢复，新的方法或数值诊断应另行冻结范围、预算和未用于选择的确认材料，不修改旧阈值、不复用已看过的持出来制造成功。
