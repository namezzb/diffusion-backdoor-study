## 固定配置与不能混淆的差异

固定配置见 [config.json](config.json)。主线是**公开数据上的SD1.5 cat目标复现**，不是论文表1三个目标均值的精确重建。三组分别为 `masq`、`poisoned`、`benign`；前两组使用同一10图混合数据，正常组仅用7张汽车图。均训练25 epochs；前两组250步，正常组175步。训练seed42，rank为UNet16/TE8，UNet/TE学习率分别4e-4/5e-5。评估采用官方推理示例的50步、CFG9、底座PNDM，seed从100000起逐一递增，各组两类提示各5000张。首轮合计30000张，批量4。

| 差异/缺口 | 处理及影响 |
|---|---|
| 官方重复触发样本2次，使公开数据有效投毒比例变为6/13 | 本轮不复制，保持论文声明的3/10；这是明确配置差异，不能宣称逐行复现官方默认训练 |
| 官方`bias=lora_only`会训练底座bias，与冻结底座叙述冲突 | 本轮采用`bias=none`，断言可训练参数全部为LoRA；实际3778560个可训练参数，与论文表1参数计数不一致 |
| 官方对不同层另乘1.5/1.2等学习率因子 | 本轮按论文列出的UNet/TE独立学习率；不使用未在正文给出的逐层倍率 |
| LoRA训练时alpha/r=1.2，官方导出未明确保留缩放元数据 | 本轮将倍率折入B矩阵；用全新底座加载后的TE/UNet前向数值验证有效权重一致 |
| 官方训练异常被捕获后仍继续计步；resume_step未实际跳过数据 | 本轮异常退出并保存进度，按优化器步恢复，失败尝试单独保留；每步固定随机输入使重启可重建对应批次 |
| 依赖版本与官方requirements不同 | 复用已部署兼容环境，版本分别记录，以真实加载和训练/生成验收，不假装软件栈逐版本相同 |
| 官方未公开完整评估器、Gemini判定提示、参考分布与组合伙伴 | 本轮记录CLIP十类top1、ImageNet ViT猫类top1两个**代理ASR**，另记录SMI和正常prompt的CLIP余弦；Gemini ASR、FID、LPIPS不伪填 |

训练和生成都是有限任务。每组最大训练尝试1000次、生成尝试11000张，断点不清零；普通技术失败退出并可续跑。每组只由指定worker写入，没有锁。已有PNG缺评分时续评分；完整评分跳过。GPU0负责Masq，GPU2依次负责Poisoned和Benign，避免对同组并发写入。两类提示按批次交错生成，保持部分结果可比较；不改变已固定的每图prompt、seed或总数。

## 与当前idea直接相关的阅读结论

| 工作 | 当前应采用的边界 |
|---|---|
| [MasqLoRA §5.4](https://arxiv.org/html/2602.21977v4#S5.SS4) | 表3是多份MasqLoRA堆叠，公开实现未给出组合脚本、伙伴及系数；不能直接推成任意良性伙伴或ZipLoRA/K-LoRA下都有效 |
| [PoisonLoRA §5.4](https://arxiv.org/html/2606.09151v1#S5.SS4) | 已明确研究恶意LoRA与良性LoRA不同比例组合、底座切换和后续再混合；“一份恶意LoRA经过组合仍有后门”本身已不是空白 |
| [LoRango](https://arxiv.org/html/2609.25884v1) | 控制两份匹配适配器，以配对身份触发；权限与只控制一份恶意资产的设定不同 |
| [LoBAM](https://arxiv.org/html/2411.16746v4) | 恶意更新放大提供对照思路，论文实验主要是视觉分类融合，不能把结果当作T2I适配器证据 |
| [TokenScanner](https://arxiv.org/abs/2609.31878) | 新近工作扫描TE/UNet的token响应；后续若用响应定位或检测，要核对它与旧TCL思路的重叠 |

对idea的推论：先明确用户实际使用的融合算子、攻击者可见的伙伴信息、正常主体/风格保留指标，再判断尚未覆盖的失败条件。首轮产出的独立适配器、相同seed配对图和逐图评分可直接作为这种检验的基础；尚不把任何新idea记为已验证。
