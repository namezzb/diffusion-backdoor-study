## 4. 参数筛选与对照

先定义差分`Δ=θb−θc`，其中`b`为后门TE、`c`为匹配干净TE；范围是整个TE的命名浮点参数，排除缓冲区及去噪网络参数。所有差分从原文件以FP32计算，按固定层名、参数名及展平顺序切为最多2^19个标量的块，尾块独立保留，最多1024块。

记`hθ`为实际送入去噪网络的最终、固定长度词元表示，`p★`为真实触发提示，MSE为均方误差，即逐元素差的平方再平均。

\[
R(\theta)=\mathbb E_p\operatorname{MSE}\left(h_\theta(p^*)-h_\theta(p),\ h_c(p^*)-h_c(p)\right).
\]

每次把一个块G恢复为干净值，得到`b\G`；正常代价`C_G`取狗、猫、其他对象三组中最大的平均`MSE(h_{b\G}(r),h_b(r))`。块评分为`[R(b)−R(b\G)−C_G]/|G|`，即单位参数带来的触发响应净减少量，只用于提出候选，不当作图片效果结论。

| 项目 | 确定性规则 |
|---|---|
| 新筛选组 | 正分块按评分降序、参数路径和块起点打破同分，依次接纳不超过全TE参数量5%的完整块，放不下的块跳过；记录实际数量K，K=0或组合恢复后R不改善时停止。 |
| 旧式幅度对照 | 在同一TE参数全集按绝对差分取最大的K个坐标，同分按路径和坐标；这是同数量的旧式筛选规则，不复用旧run冻结掩码。 |
| 同块幅度对照 | 匹配新组各层、各块尺寸档的数量，在每档按块内平均绝对差分选取；报告其与新组的重叠，不要求幅度最大与差分范数同时相等。 |
| 随机对照 | 3组固定随机种子的随机块，匹配新组各层、各块尺寸档数量及差分L2范数（整体改动大小），范数相对误差≤10%；每组最多尝试1000次，须彼此不同且不同于新组，否则记对照不足并停止，不缩放权重凑数。 |
| 八个版本 | 干净模型、未恢复后门模型、新组恢复、旧式幅度恢复、同块幅度恢复、3组随机恢复；各组均报告K、逐层数量、差分范数和掩码哈希，掩码是选中参数位置的记录。 |
| 冻结与缓存 | 缓存干净／后门TE输出，逐块只评一次，六个恢复版本各最多复核一次组合；确认图出现后不重选块、调正常惩罚、改比例或增加候选。 |

激活变化的位置不能直接当作权重位置，本实现必须实际恢复确定的参数块再测影响。正常与后门功能可能重叠，A称“候选触发相关组”、B称“其余组”，不宣称已经分出纯后门与纯正常参数。

## 6. 预登记判据与结论

定义`ASR`为触发图生成目标猫的攻击成功率，`ACC`为正常提示生成正确对象的比例；`D_m=ASR_bd−ASR_m`是恢复版本m带来的攻击下降量。对照只有通过同一正常门槛才参与ASR优劣比较，正常失格单独记录，不能用破坏正常能力换来的攻击下降宣称有效。

| 检查 | 判据 |
|---|---|
| 源基线有效 | 后门源模型触发ASR≥75%，且高于干净源模型至少50个百分点；后门源模型三类正常ACC分别≥75%，不满足记为该基线不适合检验，而非新筛选已失败。 |
| 正常能力 | 每个状态下，正常狗、正常猫、其他对象分别相对未恢复后门基线检查，ACC下降≤5个百分点、平均CLIP图文匹配分数（0—100尺度）下降≤1分；均值及不确定性均报告，不把点估计达标写成已证明等效。 |
| 源定位实用门槛 | 新组正常达标且`D_new≥25`个百分点；对正常合格的两种幅度法各要求`D_new−D_amp≥12.5`个百分点，对3组正常合格随机法分别要求`D_new>D_random`。 |
| 合并可判定 | 先计算`δ=ASR_bd_merge−ASR_clean_merge`，须δ≥25个百分点且未恢复后门合并模型三类正常ACC各≥75%才评价迁移；否则分别记信号不足或正常基线不合格，不换模型、比例或提示补救。 |
| 合并迁移门槛 | 新组正常达标且`D_new≥0.5δ`，对正常合格幅度法各要求`D_new−D_amp≥0.25δ`，并优于正常合格随机法；这是本次出图前明确的新相对判据，避免低攻击基线时机械要求下降25个百分点。 |
| 统计报告 | 以128个上下文为抽样簇，两个种子在簇内平均，按相同上下文对所有版本做10000次配对bootstrap（重复抽取上下文估计误差）；报告95%区间、原始分子／分母和配对差，不能把256图当成256个独立文本。 |
| 主比较证据 | 新组相对两种合格幅度法的下降量优势另报告各97.5%双侧bootstrap区间，用Bonferroni分配两项比较的误差预算；只有两项下界均大于0才称主比较得到统计支持，三个随机对照作为次要证据描述。 |
| 样本纪律 | 正常每类每版本256图，一张为0.390625个百分点；区间不确定时如实报告，不在看过结果后追加样本、改门槛或只展示表现好的种子。 |

源阶段达到实用门槛且至少一个幅度对照正常合格时可进入预定合并阶段，但区间跨0必须标注“定位优势证据仍不确定”；全部幅度对照失格时只报告可行性优势，合并阶段记`skipped`，不冒充已经证明优于幅度筛选。正常猫损失超限时，即使攻击下降也判为不合格，不能称精准定位。

在有效输入和完整对照下不达预设门槛可形成负结果；基线信号不足、随机匹配失败、数据缺失或实现错误形成无法判定，不冒充方法无效。两阶段通过仍只支持本模型和固定开发合并条件下的定位改进，下一轮是否优化a/b和增强攻击另行设计。
