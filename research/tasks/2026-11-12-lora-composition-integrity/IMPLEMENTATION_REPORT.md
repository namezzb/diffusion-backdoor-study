# LoRA 部署条件下的生成语义完整性

用户的精读笔记指出，MasqLoRA 表 3 的变量是堆叠适配器份数。笔记区分了部署缩放、秩、有效更新强度和伙伴位置。PoisonLoRA 已研究与良性适配器的配比变化及再混合，LoRango 已研究匹配伙伴共同加载时的异常行为。用混合比例和伙伴名称作一般横轴，方法贡献容易与这些论文重叠。本次实证研究部署后的防御与正常生成效用。原权重和实验历史均作只读证据。 [用户笔记](../2026-11-04-lora-merging-reading/总结/When_LoRA_Betrays_Summary.md) · [MasqLoRA §5.4](https://arxiv.org/html/2602.21977v4#S5.SS4) · [PoisonLoRA §5.4](https://arxiv.org/html/2606.09151v1#S5.SS4) · [LoRango](https://arxiv.org/abs/2609.25884)

三个候选共同针对一个问题。正常 LoRA 引起的构图和媒介变化也会降低对象的绝对图文相似度，审计器需要在相同报警预算下识别真正的对象错配。

| 候选 | 可证伪假设 | 对照 |
|---|---|---|
| 用同场景对照提示做相对评分 | 只改变主对象，保留其余描述，能减小媒介和构图对全局评分的影响 | 全局主对象分数、只用对象词的分差、分层与全局校准 |
| 局部图像证据 | 主体偏小或与其他对象共现时，重叠局部视窗能帮助识别主体是否仍在 | 全图对象分差、相同阈值协议、同一图像 |
| 可信底模参照 | 同场景可信图像可提供正常对象分差的参考，扣除参考后更容易识别真实偏离 | 同一场景分差、同场景但独立 seed 的底模参照、相同阈值协议 |

SugarCrepe 和 GenEval 已研究细粒度图文对照与对象级组合评价。相对评分或分块本身已有先例。潜在贡献在于将这些测量与 LoRA 部署状态结合，在不同媒介和对象共现条件下验证报警率和正常语义。TokenScanner 提供模型级与输入级审计，UFID 通过反复查询考察输出一致性。要主张 SOTA，需同一语料、阈值和独立标注下的正面对照，并明确单图额外计算。 [SugarCrepe](https://arxiv.org/abs/2306.14610) · [GenEval](https://arxiv.org/abs/2310.11513) · [TokenScanner](https://arxiv.org/abs/2609.31878) · [UFID](https://arxiv.org/abs/2404.01101)
