# 特殊字符触发的参数定位验证：初始小样本草案

日期：2026-10-29；用户认可方向并要求扩大样本后，已接续为[独立任务](tasks/2026-10-29-trigger-contrast-localization/TASK.md)，当前方法、预算和状态以该任务为准。下文保留初始2048图草案，未执行、不再作为当前预算，也不恢复旧run。

## 1. 要验证的判断

同一句提示的“有触发／无触发”对照，比普通狗／猫对照更能针对触发机制，但响应差仍不直接等于后门权重。首轮检验：**同样数量的参数被恢复为干净值时，新筛选能否更多地压低触发攻击，并保住正常狗、猫及其他对象的生成能力。**

先用“恢复干净值”检验参数是否有因果贡献，再考虑保留或放大这些参数；本轮不训练a/b，也不把定位成功写成合并后攻击增强。

## 2. 经典方法与本轮对象

| 方法 | 已核对的触发形式与本轮意义 |
|---|---|
| Rickrolling the Artist，ICCV 2023 | 微调文本编码器，支持单字符、同形异码字符等触发；TPA（目标提示攻击）使模型转向固定目标描述，适合现有文本编码器差分实验。 |
| BadT2I，ACM MM 2023 | 官方代码支持零宽空格触发并提醒分词环境会影响其是否保留，说明不能只看提示在屏幕上的外观。 |
| EvilEdit，ACM MM 2024 | 官方默认示例使用普通短语“beautiful cat”触发“zebra”，修改去噪网络；不能将不同触发形式或修改部件混成同一实验。 |

只使用现有Rickrolling TPA模型权重及其匹配干净模型，修改范围为整个TE（文本编码器，把提示转换成模型使用的数值表示）。实际触发规则沿用[来源已核验的配置](tssa_mvp_2026-10-26.json)：所有小写`o`（U+006F）替换成`ȏ`（U+020F），目标保持`A photo of a cat`，不擅自改为保留原场景的对象替换攻击。

示例配对：`A dog on the beach` ↔ `A dȏg ȏn the beach`；`[T]`仅表示触发操作，不是新增一个未经训练的词元（分词器输出的文本单位）。若目标本来是猫，`猫/[T]猫`不适合作为主要攻击样本，正常猫应作为单独的能力保护对照。

## 3. 筛选方法：响应对比加实际参数干预

| 步骤 | 拟固定的做法 |
|---|---|
| 配对与校准 | 16个新定位上下文，构造触发狗、原始狗、正常猫和其他对象四类提示；干净与后门TE均计算，扣除干净模型本来就有的字符响应。 |
| 参数单位 | 整个TE的浮点参数按层、参数名和展平顺序切为最多含2^19个标量的块，尾块保留；最多1024块，超出即在实施前修订预算，不临时扩张。 |
| 逐块干预 | 每次只把一个块恢复为匹配干净值，测“额外触发响应减少量”和三类正常提示中最大的平均响应损伤；使用前向计算，不依赖此前未通过校验的梯度。 |
| 形成A组 | 按单位参数的净收益排序，仅取正收益的完整块，实际总量不超过全TE的5%；A为候选触发相关组，余下为B，不称为两套纯净独立参数。 |
| 冻结后验收 | 新组与全部对照一次冻结，随后在新图片上验收；若组合恢复后的响应不再改善，直接记录筛选失败，不看确认图后改分组。 |

评分定义：`hθ`固定为实际送入去噪网络的最终、固定长度词元表示，`c`为干净模型、`b`为后门模型、`p★`为真实触发提示；MSE为均方误差（逐元素差的平方再平均）。

\[
R(\theta)=\mathbb E_p\left[\operatorname{MSE}\big(h_\theta(p^*)-h_\theta(p),\ h_c(p^*)-h_c(p)\big)\right].
\]

对参数块G恢复得到模型`b\G`，正常代价`C_G`取狗、猫、其他对象三组中最大的平均`MSE(h_{b\G}(r),h_b(r))`；评分为`[R(b)−R(b\G)−C_G]/|G|`，同分按参数路径排序。该分数只提出候选，既不保证剔除了所有混杂，也不代替图片攻击率。

按排序依次接纳不超预算的完整块，超出的块跳过；无正收益块或最终K=0即记定位失败，不生成空掩码成功结果。

## 4. 对照、样本与预算

| 项目 | 待review的范围 |
|---|---|
| 八个模型版本 | 匹配干净模型、未恢复的后门模型、新筛选恢复、同块尺度幅度恢复、旧式逐参数幅度恢复、三组随机恢复。 |
| 公平比较 | 记新组实际参数数为K；旧式幅度法取相同K个最大绝对差分坐标，同块幅度法在每层、每个块大小档内按块的平均绝对差分取新组相同配额，所有版本报告实际差分范数。 |
| 随机对照 | 匹配新组各层的块尺寸、数量及差分L2范数（各差分平方和的平方根，衡量整体改动大小），范数误差不超过10%，只用权重信息且三组随机数固定；每组至多尝试1000次，须得到彼此不同且不同于新组的掩码，否则停止并记录比较证据不足，不缩放权重伪造等范数。 |
| 图片输入 | 另16个全新确认上下文，四类提示各配两份相同初始噪声；提示不复用旧持出集，各版本共享生成配置、提示和噪声，随机数不当作独立上下文。 |
| 第一阶段 | 原始源模型：8版本×4类×16提示×2随机数＝最多1024图；先评价两个基线，其结果计入本阶段预算。 |
| 第二阶段 | 第一阶段通过才使用同一批冻结掩码（选中参数位置的记录），测试一个固定开发合并状态：25%源模型＋75%既有Edev开发模型，最多再1024图；这是同一确认提示上的开发状态迁移检查，不宣称未见专家或独立数据泛化。 |
| 总上限 | 2048图、0训练更新；TE定位前向另记账，最多`(1024+8)×64=66048`次单提示TE前向等价量，不混写成图片数或去噪网络前向数。 |

第二阶段使用`θmerge=0.25θb+0.75θEdev`，恢复G时只减去`0.25ΔG`，其中`Δ=θb−θc`；匹配干净参考为`0.25θc+0.75θEdev`。其他组件与旧开发合并定义一致，重新绑定组件哈希，不把源模型整份差分直接从合并模型扣掉。

定位阶段缓存干净／后门基线输出，六个恢复版本各最多复核一次组合，不额外试探组合；出图过程中使用TE的计算计入图片执行账，不重复算入定位前向预算。

## 5. 预设验收与停止条件

| 检查 | 拟定门槛与解释 |
|---|---|
| 输入和基线有效 | 核对字符编码、分词结果、组件哈希；源模型触发ASR至少75%、高于匹配干净模型至少50个百分点，且源后门模型三类正常正确率各至少75%，否则记录基线不适合本轮定位检验。 |
| 新筛选有效 | 新组通过正常门槛且ASR至少下降25个百分点；对同样通过正常门槛的对照，须比两种幅度法各多下降至少12.5个百分点、下降量优于三组随机，失格对照只记正常能力失败，不混比其ASR。 |
| 正常能力保留 | 正常狗、正常猫和其他对象分别统计，相对同状态未恢复模型的正确率下降不超过5个百分点、平均CLIP图文匹配分数（0–100口径）下降不超过1分；评分器、类标签与口径在出图前冻结。 |
| 合并可判定 | 该固定合并基线触发ASR须高于匹配干净合并至少25个百分点，否则记为信号不足，不更换专家或比例继续搜索；可判定时使用同样的定位和正常门槛。 |
| 证据报告 | 提供逐图结果、配对差、按提示聚类的不确定性估计及匿名图片检查；每类32图，一张相差3.125个百分点，上述门槛仅为探索筛选标准，不是显著性或等效性证明。 |

ASR是触发图生成目标猫的比例，下降用于检验该组参与攻击；若全部对照正常失格，新组通过只证明本预算下的可行性优势，不声称已获得相对对照的ASR差值优势。

正常猫能力损失超出门槛而攻击下降，判为破坏目标生成能力，不能算精准定位；源模型通过、合并失败，说明定位未迁移到该开发状态。两阶段都通过，也只支持本模型、本预算下的筛选改进，a/b优化与攻击增强须作为另一个待设计实验。
