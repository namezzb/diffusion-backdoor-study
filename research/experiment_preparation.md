# TSSA 梯度版实验前准备

日期：2026-10-26；[v2-gradient完整方案](tssa_response_calibration_method_proposal.md)已获用户认可，当前仍未实现或验证。本清单安排下一阶段工作，不表示论文下载、远端盘点、指标复测或训练已经启动。

## 执行顺序

论文补齐与本地协议整理可并行进行，远端只读清单完成后再选定模型和基线。首轮仅围绕Rickrolling类TE后门推进，不要求重新训练BackdoorDM全部16种攻击。

| 顺序 | 工作 | 完成标志 |
|---|---|---|
| 1 | 核对论文并补齐缺失正文 | [论文下载队列](../papers/download_queue.md)逐项更新，标题、作者、标识与PDF内容一致 |
| 2 | 远端只读清单与来源身份 | 模型、数据、配置、指标CSV、环境与资源状态可追溯 |
| 3 | 同一checkpoint基线 | 所选源模型的ASR、正常能力及所需质量指标来自同一模型 |
| 4 | 专家与评价协议 | Edev/Ehold、提示划分、采样设置和验收门槛固定 |
| 5 | 实现检查与低预算首轮 | 参数图与教师正确，静态筛查通过后完成三族公平对照 |

## 1 论文补齐

- [ ] 按[下载队列](../papers/download_queue.md)核对核心攻击、合并、基线与评价论文，优先补当前方案直接依赖的正文和代码来源。
- [ ] 为每篇核心论文记录威胁模型、优化变量、正常保持项与评价协议；相似公式不直接等同于同一任务或可直接比较的方法。
- [ ] 对本地PDF的标题、年份、arXiv/DOI和索引做一致性检查；无法确认的条目保持“待核验”，不凭文件名判定已读或已复现。

## 2 远端只读清单与来源身份

- [ ] 使用用户最近提供的有效AMAX端口，仅先读取任务/环境/GPU与模型状态；旧端口和旧“空闲”日志不代表当前可用。
- [ ] 从[结果索引](../results/README.md)列出的路径导出文件清单，记录checkpoint哈希、配置、训练seed、trigger/target、评估CSV与样本数。
- [ ] 选择唯一Rickrolling后门源θb及匹配干净源θc，确认非TE组件相同、架构与tokenizer兼容；同时记录评估器和真实图参考集身份。
- [ ] 核对历史模型是否被后续重训覆盖，建立run与checkpoint的一一对应关系；已有CSV不能仅凭方法名称归入新基线。

交付物为模型及指标来源清单和待复测缺口表；这一步不启动训练、不清理历史产物。

## 3 同一checkpoint的基础指标

- [ ] 先解决Rickrolling混模型问题：历史ACC/ASR/CLIP/FID使用seed678、LPIPS使用seed100，选择一个源模型后统一绑定指标。
- [ ] 先验证干净源和后门源能按固定协议正常出图，再复核触发ASR、正常ACC、独立图文评分与配对正常图像；记录成功数/总数及失败案例。
- [ ] 若复用旧指标，须同时匹配checkpoint哈希、数据、评估器、采样器、步数与seed；不匹配项列为复测，而非默认沿用。
- [ ] 正式质量结论使用同协议足量FID及预登记退化门槛，项目正式口径为10K；小样本出图筛查与10K生成分别记预算。

源模型正常能力不合格或触发行为不可靠时，先定位基线问题，不通过调整新方法门槛掩盖来源缺陷。

## 4 独立专家与评价协议

- [ ] 选一个独立开发专家Edev和一个未用于开发的Ehold，记录完整UNet/TE差异；base加裁剪恶意增量不作为独立专家。
- [ ] 固定Dfit为8对提示＋8条额外正常提示、Dval为4对＋4条、Dtest为8对＋8条；按模板和语义划分，不能只换seed冒充持出。
- [ ] 固定DDIM25步、ηDDIM=0、CFG=7.5、512×512、空负面提示和paired seeds；若来源攻击必须采用其他设置，先同步修改方案和预算再执行。
- [ ] 开发条件固定Edev下α=0.08/0.25/0.50，上传α=1另查正常能力；持出使用Edev/0.15、Ehold/0.25、Ehold/0.15及上传状态。
- [ ] 明确ASR_ViT与ASR_GPT区别、额外正常提示的对象标签、独立评分器版本和分数尺度；新方法、干净参考与对照共用协议。
- [ ] 登记响应门槛与图像门槛：正常代理不比naive更差，正常ACC相对matched-clean下降不超过5个百分点、提示一致性下降不超过1分；小样本通过不等于总体质量保证。

## 5 实现检查与低预算首轮

| 阶段 | 待办 | 通过标准 |
|---|---|---|
| 结构检查 | [ ] 固定ΔA/ΔB、原始教师、β与系数范围，验证α方向及a/b计算图 | 优化器只更新a/b，教师不随学生变化，前向完整使用合并环境 |
| 公共缓存 | [ ] 保存16条合法轨迹及3个时间点，生成固定B★和干净参考 | 提示、latent、实际timestep与模型身份可追溯 |
| 静态筛查 | [ ] 评价naive、Uniform4、Uniform16、TSSA16及clean | 按方案检查响应与出图矛盾，代理失灵时停止 |
| 公平学习 | [ ] Uniform-GD、TSSA-GD、RC-TSSA-GD各48步 | 共144次更新，共用损失、数据、β=1及初始化预算 |
| 开发选择 | [ ] 保存24/48步候选，先过正常门槛再比较验证ASR | 无合格候选记失败，保留静态基线及完整筛选表 |
| 独立持出 | [ ] 每方法冻结一个checkpoint，按预设四状态评价 | 不再使用持出结果调a/b、β或筛选候选 |

首轮上限为1,664张完整图、91,848次前向branch-NFE，另计144个更新的反向成本、TE/VAE/评分器及I/O；模型来源复测、额外诊断、重试和正式10K FID均单独记账。预算与停止条件以[完整方案第10–11节](tssa_response_calibration_method_proposal.md)为准，不用“只学两个标量”推算GPU时长。

未来本地结果使用 `results/tssa-gradient/<run_id>/`，最低文件要求见[结果索引](../results/README.md)。每轮同时保留失败结果、逐样本指标、模型哈希、a/b轨迹与资源消耗，当前不创建空的实验结果目录。
