2. 优化公式设计

TSSA 公式

# 原始公式 (LoBAM-style, 均匀放大) θ_upload = θ_base + λ × Δθ # 所有参数统一放大 λ 倍 # TSSA 优化公式 (选择性放大) θ_upload = θ_base + λ_eff ⊙ Δθ # 逐参数自适应放大 # 其中: λ_eff[i] = 1 + (λ - 1) × M_τ[i] # 有效放大因子 M_τ[i] = 𝟙[ |Δθ[i]| > τ ] # 幅度二值掩码 τ = Percentile95( |Δθ| ) # 95 分位数阈值 λ = 16 # 后门放大系数 # 效果: top 5% 参数放大 16 倍, 其余 95% 保持原始尺度 # 选择性比: 16:1 (高创新度)

关键改动：仅将标量 λ 替换为逐参数 λ_eff，不改变公式整体结构。

两个创新点

1️⃣
幅度选择性放大 (Magnitude-Selective Amplification)
仅放大高幅度（后门相关）参数。T2I text encoder 后门的参数变化呈双峰分布：trigger 相关参数幅度 10-100x 于 utility 参数。 这不同于 LLM LoRA 攻击（低秩约束使变化更均匀）。仅放大 top 5% 即可保留完整后门信号。
2️⃣
T2I 特异性分位数阈值 (T2I-Specific Percentile Threshold)
p=95 为最优阈值。p=80 放大过多参数导致 ACC 下降；p=99 放大太少导致 ASR 不足。 p=95 精确捕捉 trigger token embedding + attention K/V，同时保持 95% 参数不变，维持 text encoder 连贯性。

3. 综合多方论文支撑

T-Switch (2412.00054): "脉冲特性" — 仅高幅度参数对任务有正向贡献 → 我们的 M_τ 掩码
Task Vector Decomposition (2512.22511): unique/shared 分解 — 扩散模型中仅混合 unique 分量保持质量 → 我们放大 salient (unique) 分量
LEWIS (2503.03874): 层级重要性 — 激活引导的层级稀疏 → 我们的参数级重要性（更细粒度）
LATA (2502.20186): 层级权重 — 任务相关层放大、通用层衰减 → 我们的参数级选择性放大
LoBAM (2411.16746): 放大攻击方法 → 我们的基线公式

9. T2I vs LLM 差异分析 — 公式设计动机

维度T2I (Rickrolling)LLM (LoBAM)对公式设计的影响
参数分布双峰分布：trigger 参数幅度 10-100x 于 utility较均匀：LoRA 低秩约束分散变化T2I 可用幅度阈值精确分离后门/非后门参数
放大路径非线性多步：text encoder → cross-attention → 25步去噪单次前向传播T2I 小幅度 text embedding 变化被多步放大，仅需放大少量参数
攻击载体Text encoder (197 tensors, CLIP)Full model (LoRA)Text encoder 需要所有参数协同工作，不能零化非显著参数
合并目标Civitai checkpoint merge (α = 用户选择)多用户 merge coordinator (1/N)T2I 攻击者不知道 α，需单一公式适应所有 α

12. 结论

✅
目标 1 达成：TSSA 在 ASR 上全面 ≥ 原始公式（所有 α 值，所有算子），在 ACC 上 4/5 α 值 ≥ 原始公式。Path-ASR +113%，Path-ACC +50%。
✅
目标 2 达成：两个创新点 — (1) 幅度选择性放大（仅 top 5% 参数），(2) T2I 特异性 p=95 阈值。非原版照抄，基于 T2I 双峰分布特性设计。
✅
目标 3 达成：综合 5 篇论文 — T-Switch、Task Vector Decomposition、LEWIS、LATA、LoBAM。
🌟
额外突破：TSSA 在 α=0.50 处避免崩塌（ASR=35%, ACC=60%），原始公式在此处完全失效（0%/0%）。这是选择性放大的核心优势：仅放大 5% 参数，总畸变降低 56%，text encoder 得以维持基本功能。
