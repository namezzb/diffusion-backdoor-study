# 历史汇报材料

本目录保留既有汇报 PPTX 及其生成脚本，文件内容和位置均未改变；它们是历史研究材料，不代表当前 v2-gradient 方法已经取得实验结果。

| 文件 | 内容 |
|---|---|
| [diffusion_merging_backdoor_research.pptx](diffusion_merging_backdoor_research.pptx) | 扩散 checkpoint 合并与后门研究的历史汇报。 |

依赖记录在根目录 [package.json](../package.json) 与 [package-lock.json](../package-lock.json)，生成器仍使用原有 PPTX 绝对输出路径；本次没有执行生成器或覆盖 PPTX。
